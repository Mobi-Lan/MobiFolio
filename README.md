마비노기 모바일에서 악보를 많이 모으다 보면 보관함은 긴 목록 하나뿐이고, 원하는 곡을 찾으려면 한참 스크롤해야 하고, 여러 곡을 이어서 연주하려면 한 곡 끝날 때마다 다시 골라야 합니다.

모비폴리오는 이 불편을 없애는 작은 프로그램입니다. 게임에 포함된 CLI(`MabinogiMobile_CLI.exe`)로 보유 악보와 악기 목록을 받아 와서, 음악 플레이어처럼 검색하고 재생목록을 만들고 연속으로 연주합니다.

## 무엇을 할 수 있나

**보관함을 플레이어처럼**
- 악보·악기 목록을 한 번에 받아 옵니다. 새 악보를 얻으면 「갱신」 한 번으로 반영됩니다.
- 제목에서 아티스트를 자동으로 알아봅니다. `백예린 - 0310`, `IU_밤편지` 같은 제목이 아티스트별로 묶이고, 초성 색인과 검색으로 바로 찾습니다.
- 자동 인식이 틀리면 직접 지정할 수 있고, 별칭(예: 아이유 = IU)도 등록됩니다.

**재생목록과 연속 연주**
- 곡을 골라 재생목록에 담고 폴더로 정리합니다. 드래그로 순서를 바꿉니다.
- 전체 연주, 셔플, 반복(전체·한 곡), 곡 사이 대기 시간.
- 곡마다 악기를 따로 지정할 수 있고, 재생 시 자동으로 바꿔 듭니다.
- 한 번 연주한 곡은 길이를 기억해 목록과 남은 시간에 표시합니다.
- 같은 제목의 악보가 여러 장 있어도 한 장씩 따로 관리됩니다.

**그 외**
- 최근 재생, 곡 정보 카드, 다음 재생 큐.
- 테마 자동(OS 설정) · 다크 · 라이트.
- 게임에서 직접 연주를 시작해도 플레이어가 상태를 따라갑니다.
- 합주 인식: 주변에 같은 곡을 여러 채널로 연주하는 사람이 있거나 내 보관함에 없는 곡을 연주 중이면 합주로 보고, 상대 곡이 끝나는 시점에 내 연주도 함께 멈춥니다(다음 곡으로 넘어가지 않음). 설정에서 끌 수 있습니다.

## 두 가지 판

| | 경량판 | 정식판 |
|---|---|---|
| 파일 | `MobiFolioLite-<버전>.exe` 하나 (약 9MB) | `MobiFolio-Setup-<버전>.exe` 설치 프로그램 (약 120MB) |
| 창 | Edge 앱 창 (Windows 기본 내장) | 자체 창 (Electron) |
| 설치 | 필요 없음. 받아서 실행 | 설치 마법사, 시작 메뉴·바탕화면 바로가기 |
| 자동 업데이트 | 지원 (새 버전 알림 → 한 번 클릭) | 수동 (새 설치 파일로 덮어쓰기) |

처음이라면 **경량판**을 권합니다. 두 판은 같은 데이터를 쓰므로 나중에 바꿔도 재생목록이 그대로입니다.

## 미니판 (MobiFolioMini.exe)

게임 화면 옆에 두고 쓰는 세로형 창(440×920)입니다. 백엔드는 같고 화면만 다릅니다. 게임 보관함처럼 악보가 두루마리 격자로 쌓이고, 기능은 재생목록(담기·제거·순서·곡별 악기), 재생·셔플·한 곡 반복만 있습니다. 정식판·경량판과 같은 데이터(재생목록·설정)를 씁니다. 자동 업데이트는 없으며 새 exe 로 바꿔 넣으면 됩니다.

- 곡을 한 번 누르면 선택, 두 번 누르면 바로 연주. 선택하면 아래에 「재생 · 담기 · (재생목록에서) ▲ ▼ 제거」 막대가 뜹니다.
- 우클릭: 지금 연주 · 재생목록에 담기 · (재생목록에서) 이 곡 악기 지정 · 제거.
- 위쪽 알약: 전체 · 최근 · 재생목록들 · 「+ 목록」. 재생목록을 열면 「▶ 전체」와 이름 변경·삭제 메뉴가 있습니다.

## 필요한 것

- Windows 10 또는 11
- 마비노기 모바일 PC 클라이언트, 게임 안에서 CLI 옵션 켜기
- 경량판은 Microsoft Edge (Windows에 기본 포함)

## 시작하기

1. [다운로드 페이지](https://fo.mobimml.com)에서 경량판 exe를 받아 원하는 폴더에 두고 실행합니다.
2. 게임을 켜고 CLI 옵션을 켠 뒤, 모비폴리오 상단의 「갱신」을 누릅니다.
3. 악보 목록이 채워지면 곡을 더블클릭해 연주하거나, 곡의 「+」로 재생목록에 담습니다.

첫 실행 때 Windows가 "알 수 없는 게시자" 경고를 띄울 수 있습니다. 「추가 정보 → 실행」으로 진행하면 됩니다. 이유는 [아래](#백신이-경고할-수-있습니다)에 있습니다.

## 안심하고 써도 되나요

개인이 만든 서명 없는 프로그램이라, 이 질문에는 "믿어 달라"가 아니라 **확인할 수 있는 사실**로 답합니다. 소스가 전부 이 저장소에 있으니 직접 읽고 빌드해서 비교할 수 있습니다.

**통신 범위는 세 가지뿐입니다.**
- 내 PC 안에서만 도는 로컬 서버 (`127.0.0.1`, 실행할 때마다 다른 포트와 비밀 토큰)
- 게임이 제공하는 CLI와의 통신
- 새 버전 확인 (`fo.mobimml.com`의 `latest.json` 한 개와, 「지금 업데이트」를 눌렀을 때의 exe 다운로드)

그 외에 어디로도 아무것도 보내지 않습니다. 방화벽에서 아웃바운드를 막아도 업데이트 확인만 빼고 전부 동작합니다.

**게임에는 읽기와 연주 명령만 보냅니다.**
- 게임 상태를 바꾸는 명령은 악기 바꾸기, 악보 연주, 정지 세 가지뿐입니다. 그 외는 악보·악기 목록과 연주 상태 같은 조회 명령(`get_*`, `status`)이며, 서버는 조회 명령만 화이트리스트로 통과시킵니다 (`server.py`에서 `_cli(` 호출과 `/api/cli` 처리를 검색하면 확인됩니다).
- 정령의 날개 같은 재화를 소모하는 명령(채집·제작·개조)과 채팅 전송은 호출하지 않습니다.
- 게임 메모리나 패킷을 건드리지 않습니다. 게임이 열어 둔 CLI만 씁니다.

**데이터는 내 PC에만 있습니다.**
- `%LOCALAPPDATA%\MobiFolio` 폴더에 재생목록·설정·로그가 저장됩니다. 계정 정보는 다루지 않습니다.
- 프로그램을 지우고 이 폴더를 삭제하면 흔적이 남지 않습니다.

### 백신이 경고할 수 있습니다

- VirusTotal에서 70개 엔진 중 5~6개가 "의심"으로 표시합니다. 전부 기계학습 확률 판정이고, 이름 있는 악성코드와 일치한 것은 없습니다.
- 원인은 두 가지입니다. 코드 서명이 없고(개인 개발자용 인증서는 연 십수만 원), 파이썬 프로그램을 exe 하나로 묶는 방식(PyInstaller)이 자기 자신을 임시 폴더에 풀어 실행하기 때문에 포장된 악성코드와 모양이 비슷합니다.
- 다운로드 페이지에 각 파일의 SHA256이 있습니다. 받은 파일의 해시가 같으면 배포한 파일 그대로입니다.
- Windows Defender가 격리하면 Defender의 「보호 기록」에서 해당 파일을 「허용」한 뒤 다시 받으세요.

## 알아 둘 것

- 같은 제목의 악보가 여러 장이면 앱 안에서는 따로 관리되지만, 실제 연주는 게임이 그중 하나를 고릅니다. 게임 안에서 파일명을 바꾸면 구분됩니다.
- 이름 끝에 공백이 있는 악보·악기는 게임 CLI가 찾지 못합니다. 앱이 「CLI 재생 불가」로 표시하니 게임에서 이름을 고쳐 주세요.
- 게임이 꺼져 있으면 목록은 보이지만 연주는 되지 않습니다.
- 경량판은 창을 닫으면 백엔드도 함께 종료됩니다. 창을 최소화하거나 오래 두어도 종료되지 않습니다.

## 소스에서 빌드하기

필요: Python 3.12, Node.js 20 이상, Windows.

```bat
git clone https://github.com/Mobi-Lan/MobiFolio.git
cd MobiFolio
scripts\run.cmd       :: 개발 실행 (http://127.0.0.1:19997, 브라우저로 열기)
scripts\demo.cmd      :: 게임·CLI 없이 가짜 데이터로 UI 만 보기
scripts\run_mini.cmd  :: 미니판 화면으로 개발 실행
scripts\build.cmd     :: 경량판 dist\MobiFolioLite.exe · 미니판 dist\MobiFolioMini.exe + 정식판 dist-electron\MobiFolio-win32-x64\
scripts\release.cmd   :: release\ 에 zip·설치기·latest.json·SHA256SUMS 생성
```

- 백엔드는 파이썬 표준 라이브러리만 씁니다. UI는 `ui/index.html` 한 파일입니다.
- 정식판은 Electron 44 + `@electron/packager` + `electron-builder`(NSIS). `app/` 에서 `npm ci` 가 먼저 필요합니다.
- 환경변수 `MABI_DATA_DIR`(데이터 폴더), `MABI_CLI_EXE`(CLI 경로), `MABI_DEMO=1`(데모)은 개발 실행에서만 적용되고 배포판은 무시합니다.
- 구조·보안·배포 세부는 [docs/DEVNOTES.md](docs/DEVNOTES.md), QA 기록은 [docs/](docs/)에 있습니다.

## 구조

```
server.py          로컬 HTTP 서버 · API · 재생 제어 · 경량판 창/업데이트
cli_transport.py   MabinogiMobile_CLI 호출 (인코딩·종료 코드·타임아웃)
library.py         제목 정규화 · 아티스트 인식 · 초성 · 동명 채번 · 검색
store.py           데이터 파일 (설정·재생목록·최근 재생·캐시) · 잠금 · 이전
ui/                화면 전부 (index.html) · 로고
app/               정식판 Electron 셸 (main.js · fuse.js · 아이콘)
scripts/           run · demo · build · release · publish_promo
mini/              미니판 화면 (ui/index.html · app.json = 창 크기·이름)
packaging/         PyInstaller 버전 리소스 (정식판 · 경량판 · 미니판)
demo/              데모 모드 가짜 CLI · 씨앗 데이터
docs/              개발 메모 · QA 기록 · CLI 명령 카탈로그
```

## 기여

이슈와 PR을 환영합니다. 게임 CLI 동작에 관한 것은 재현 조건(게임 상태, 악보·악기 이름, CLI 응답)을 함께 적어 주세요. 재화를 소모하는 CLI 명령을 호출하는 변경은 받지 않습니다.
