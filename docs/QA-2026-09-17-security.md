## 위협 모델
단일 사용자 게임 PC. 공격 경로는 (1) 사용자가 브라우저로 여는 악성 웹 페이지, (2) 다른 플레이어가 만든 악보 제목(복사 가능), (3) 같은 PC 의 다른 프로세스/사용자.

## 수정한 취약점
- **Electron 퓨즈 미잠금 (MED)** — `ELECTRON_RUN_AS_NODE=1 MobiFolio.exe` 가 Node 인터프리터로 동작함을 실측. `app/fuse.js` 로 RunAsNode·NODE_OPTIONS·--inspect 끔, asar 밖 앱 로드 금지. 재빌드 후 와이어 확인.
- **포트 선점·UI 위장 (MED)** — 고정 포트 19997 에 먼저 앉은 프로세스가 헬스 응답만 흉내 내면 셸이 그 페이지를 신뢰된 창에 띄우고, 그 프로세스가 알려 준 PID 를 `taskkill` 했다. 배포판은 실행마다 OS 가 준 빈 포트 + 24바이트 난수 토큰으로 백엔드를 띄우고 기존 리스너에 붙지 않는다. 서버는 `SO_EXCLUSIVEADDRUSE` 배타 바인드, 부모 PID 확인.
- **임의 실행파일 실행 (MED)** — 설정 `cli_exe` 가 존재하는 `.exe` 이기만 하면 실행됐다(`whoami.exe` 실행 실측; UNC 경로도 통과). 로컬 드라이브 절대 경로 + 파일명 `MabinogiMobile_CLI.exe` 만 허용, PATH/현재 폴더 탐색(`where`) 제거, 배포판은 `MABI_CLI_EXE`·`MABI_DATA_DIR` 무시.
- **가드 없는 GET 이 CLI 를 실행 (MED)** — `/api/cli/get_*`·`/api/activity` 를 다른 사이트가 `<img>` 로 반복 호출해 CLI 잠금을 굶길 수 있었다. CLI 를 부르는 GET 과 `/api/log`·`/api/settings` 에도 출처·토큰 검사.
- **CSP 부재 (LOW)** — 서빙 HTML 에 인라인 스크립트 sha256 해시 CSP, `frame-ancestors 'none'`, `nosniff`, `no-referrer`. 인라인 이벤트 핸들러 제거.
- **창 내 이동 검사 우회 (LOW)** — `http://127.0.0.1:19997@evil.example/` 가 접두 검사를 통과했다. `URL.origin` 비교로 교체, 권한 요청 전부 거절, 배포판 메뉴·개발자 도구 제거.
- **동시 쓰기 유실 (MED, 회귀)** — 재생목록·아티스트 op 가 잠금 밖에서 읽고-고쳐-써서 40개 동시 추가 중 3개만 남았다. op 전체를 저장소 잠금 아래로. 재검증 39~40/40, 생성 41/41.
- **빌드 재현성 (MED)** — PyInstaller 6.22.3 고정, `npm ci`, `--noupx`, 두 실행파일에 버전 리소스·아이콘.
- **정보 노출 (LOW)** — 헬스에서 데이터 경로 제거, 500 응답은 예외 종류만, 동시 연결 32개 상한, 큰 본문은 비운 뒤 JSON 400, 정규화 길이 상한·결과 메모이즈.
- **UI (HIGH 2)** — 이름 대화상자에서 Esc 가 직전 「확인」 결과를 돌려주던 문제(`returnValue` 초기화), 드롭다운 안에서 스크롤하면 닫히던 문제. MED: 백엔드가 없을 때 초기화가 예외로 죽던 문제, 재생 중인 곡을 목록에서 빼면 첫 곡으로 튀던 문제, 재생목록 API 실패 응답이 상태에 그대로 들어가던 문제, 게임에서 직접 튼 연주를 앱이 끝 직전에 끊던 문제.

## 확인해서 안전했던 것
POST CSRF(커스텀 헤더 → 프리플라이트, OPTIONS 501, CORS 헤더 없음), Host 허용목록(DNS 리바인딩 차단), PUT/DELETE/TRACE 501, 경로 탐색 전부 404, CLI 인수 인젝션 불가(argv 배열·shell 없음), UI 의 모든 삽입점 `esc()`·`textContent`, 127.0.0.1 전용 바인드, 렌더러 샌드박스·contextIsolation, 외부 리소스 없음, `npm audit` 0건, Electron 44.4.1 최신, 저장소 이력에 비밀 없음, 외부로 나가는 통신 없음.
