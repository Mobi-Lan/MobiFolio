## 대표 결함과 수정
- **잘못된 입력에 연결이 끊김 (A·G HIGH)** — POST 전체를 예외 처리해 400/500 JSON 으로 응답. titles 는 문자열 배열만, 이름 200자·본문 1MB 상한, 미지 op/id 는 400.
- **CSRF (A HIGH)** — 브라우저의 다른 사이트가 `text/plain` 폼으로 설정의 CLI 경로를 임의 exe 로 바꿔 실행시킬 수 있었다. `Host` + `X-Requested-With: scorebox` 검사, Origin 검사, `/api/cli/` 는 읽기 명령 화이트리스트, CLI 경로는 존재하는 `.exe` 절대 경로만.
- **설정 미검증으로 서버 기동 불가 (B·G HIGH)** — 숫자 `cli_exe` 가 저장되면 다음 실행에서 import 시점에 크래시. 키별 타입·범위 강제.
- **손상 파일 영구 소실 (B HIGH)** — 잘린/BOM 파일이 기본값으로 읽힌 뒤 다음 저장에 덮어써졌다. `.corrupt-<ts>` 로 격리하고 BOM 허용.
- **동시 저장 충돌 (A·B MED)** — 4스레드 300회에 826회 `WinError 32`. 전역 RLock + 스레드별 임시파일 + 재시도. 40개 동시 요청 오류 0건 확인.
- **없는 곡으로 재생 시 현재 연주 끊김 (G MED)** — 악보·악기 존재를 정지 전에 확인.
- **정지 직후 `invalid_state` 로 다음 곡으로 튐 (D HIGH)** — `play_music_score` 재시도. UI 는 같은 곡 1회 재시도 후 연속 실패 상한, 연결류 오류는 건너뛰지 않음.
- **곡 사이 대기 중 정지 버튼이 재생으로 동작 (D HIGH)**, **목록 끝에서 게임은 계속 연주 (D HIGH)**, **`advance` 예외로 영구 정지 (D HIGH)** — 각각 수정.
- **곡 길이 오기록 (A·D·G MED)** — 게임 쪽 `MusicTitle` 과 같을 때만 기록.
- **PyInstaller 임시폴더 누수 (F HIGH)** — 실행마다 18MB `_MEI*` 가 남았다(21개 확인). `/api/quit` 정상 종료 → 스스로 정리, 부모 프로세스 감시로 고아 백엔드 방지. 창 닫기 후 백엔드 종료·폴더 정리 확인.
- **포트 점유/시작 실패가 무음 (F HIGH·MED)** — 헬스 체크로 우리 백엔드인지 확인, 아니면 오류창. 실패 시 오류창 + `electron.log`. 단일 인스턴스.
- **정규화 (C HIGH)** — 등록 이름이 단어 안에 걸림(IU→Aquarium), `Ghost`→OST, 이름을 떼고 곡이 안 남는 자기 일치. 토큰 경계 매칭, 대문자 OST 만, 곡이 안 남으면 미지정. 실제 193곡: 인식 109 / 기타 84, 지적된 오분류 11건 중 8건 교정.
- **UI (E HIGH)** — 이름 대화상자에서 Enter 가 취소로 동작, 재생목록 행 악기 선택 후 라벨 미갱신, 아티스트 검색창 한글 조합 깨짐. 검색 입력은 DOM 을 유지한 채 목록만 갱신.

## 보류 (판단 필요)
- 데이터 위치를 `%LOCALAPPDATA%` 로 통합 (현재는 exe 옆 `data/`; 빌드 시 백업·복원). 
- Electron 33(EOL) → 최신 메이저 업그레이드, 앱 아이콘, 코드 서명. 로컬 전용 도구라 노출은 제한적.
- 영화 제목(라라랜드·파리넬리 등)이 아티스트로 잡히는 3건 — 묶음으로 쓸모가 있어 유지.

## 검증 기록
- 서버 스모크(임시 데이터 폴더): CSRF 403, 비객체 본문 400, 타입 오류 입력 전부 200/400 JSON, 동시 rename 40건 오류 0, 손상 파일 격리, BOM 파일 정상 읽기.
- 배포판: 헬스 응답, 헤더 없는 POST 403, 창 닫기 → 백엔드 `exited 0`, `_MEI` 미증가, 재실행·중복 실행 정상.
- 주의: 스모크 중 임시 폴더에는 악보 캐시가 없어 존재 검사가 건너뛰어졌고, 그 요청이 게임의 연주를 한 번 정지시켰다(실사용 경로에서는 발생하지 않음).
